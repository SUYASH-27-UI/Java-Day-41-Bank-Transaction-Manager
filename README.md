# Java Day 41 - Bank Transaction Manager

## About
A console-based banking application that manages accounts and records deposits and withdrawals.

## Features
- Create bank accounts
- View all accounts
- Deposit money
- Withdraw money
- Check transaction history
- Display transaction timestamps
- Validate account numbers and amounts

## Technologies
- Java
- Object-oriented programming
- Classes and objects
- Encapsulation
- ArrayList
- LocalDateTime
- Exception handling

## Files
- `Main.java` - Complete application source code

## How to Run
Compile:

`javac Main.java`

Run:

`java Main`

## Important Note
This is an educational project. Account data and transaction history are stored in memory and are lost when the program exits.

## Learning Outcomes
Practiced OOP, object collections, transaction records, date/time formatting, input validation, and account operations.
